# LINKUP – Event Pooling

https://letlinkup.lovable.app

LINKUP helps people connect through shared events. The **Event Pooling** feature lets users create events, discover events happening nearby, and join a pool of participants — making it easy to find and meet people with shared interests.

## Features

- **Browse Events** – Discover all upcoming events with search and category filters
- **Create Events** – Create a new event with title, description, date/time, location, category, and max capacity
- **Join / Leave a Pool** – Join or leave any event's participant pool in one click
- **Event Detail View** – See full event info, the participant pool, and capacity progress
- **My Events filter** – Quickly see only events you have joined

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19 + TypeScript
- Vite
- CSS Modules (component-scoped CSS)
